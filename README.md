
# 📚 Personal Library Manager

A Python-based Personal Library Management System developed as a team project by Pardis Aghamohammadrafi and Ali Akbar Farmanara.

This application helps users organize and manage their personal book collections through a simple and user-friendly system.

## 🎯 Problem

Managing a personal book collection can become challenging as the number of books increases. Finding specific books, updating information, and keeping track of a collection manually can be time-consuming.

Personal Library Manager provides a digital solution that allows users to organize their books, manage book information, and access their library more efficiently.

## ✨ Features

- **User Authentication:** User registration and login functionality.
- **Book Management (CRUD):** Add, view, update, and delete books.
- **Search Functionality:** Find books easily using relevant information.
- **Library Organization:** Store and manage book details systematically.
- **Statistics & Reports:** Generate basic statistics about the book collection.
- **Password Hashing:** Protect user passwords through hashing.
- **Data Management:** Store and retrieve library information.

## ⚙️ Installation & Usage

### 1. Clone the Repository

```bash
git clone https://github.com/aghamohammadrafipardis-tech/personal-library-manager.git
```

### 2. Navigate to the Project Directory

```bash
cd personal-library-manager
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python main.py
```

**Note:** Make sure Python 3 is installed. Replace `main.py` with the actual entry-point filename if necessary.
